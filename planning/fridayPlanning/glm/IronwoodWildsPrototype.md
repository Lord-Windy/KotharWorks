# Ironwood Wilds — Prototype Slice ("The Landing")

> **Status:** planning document. Defines the first vertical slice: what it
> contains, a full worked session showing how it plays, the module skeleton
> it lands in, milestones with acceptance criteria, and how it maps to `st`
> tickets. No code exists yet — code sketches here are the design.

## 1. The slice's job

Prove the whole spine end-to-end, thin:

> **Queue timed actions for a few patient characters over HTTP, walk away,
> come back to finished work and a living event feed, ship goods home for
> Favor, fight one autobattler expedition, survive one preplanned raid —
> and know that the entire session can replay bit-for-bit from a seed and a
> log.**

Everything exotic (births, awareness scaling, ironwood economy, myth layer,
legacy) is deliberately *out* — but nothing in the slice is throwaway: every
file it creates is a permanent resident of the module map (Architecture §3).

## 2. Scope

| In | Out (v0 of the slice) |
|---|---|
| 1 account, 1 household, 3 colonists (fixed roster) | registration choice, births, roster growth |
| 1 world seed, 3×3 pre-materialised regions | unbounded lazy regions (the *machinery* ships lazily; the slice just bounds it) |
| Terrain/biome/deposit/site passes (1–6 of the pipeline) | lair-placement pass, names beyond basics, myth pass |
| Actions: `travel, chop, forage, mine, build(camp→storehouse), craft(bandage, spear), rest, stage, dispatch` | tech tree gating (one dummy node only), skills beyond Woodcutting/Mining/Arms (xp accrues, levels 1–10) |
| One lair type, one creature ("gnarlings"), party of 3, fixed standing-order presets | loadout variety, wounds/herbs system |
| One scheduled raid on the hold, one defense-plan template | awareness dial, severity scaling |
| Favor from one shipment; Favor buys 1 recruit | ladder, legacy, season end |
| REST + SSE + auth-lite (single token) + `/play` web page (tabs, queue editor, chronicle pane) | spectator pages, leaderboard, atlas page |
| Postgres command log + snapshot + replay tool (`wilds-headless`) | projections beyond chronicle_events, season archive flow |
| Reference bot `apps/wilds-bot` with a hand-written greedy `Doctrine` | anything genetic |

## 3. A worked session (how it plays)

*What follows is a real transcript shape: every line corresponds to a
documented API call or SSE event. Numbers assume the tunable defaults.*

**Day 0, tick 0.** The server starts season 0 (seed `1643…`, rules v1). You
register, found household **Ashford**, pick landing site 2 of 3 ("a hemlock
hollow above Harrow Ford" — generated by the name + description passes).

**t=0.** `GET /v1/household` → Mara (Woodcutting 3), Pell (Mining 2), Jory
(Arms 1). All idle. Standing on the landing camp tile.

You open three tabs. In Mara's tab you post one command:

```json
POST /v1/commands
{ "cmdId": "0192f3c1-…", "type": "enqueue", "character": "chr:1:0",
  "actions": [
    { "action": "travel", "to": "reg:0:-1/tile:30/12" },
    { "action": "chop",  "target": "site:reg:0:-1:14", "count": 4 },
    { "action": "travel", "to": "reg:0:0/tile:44/9" } ] }
→ 200 { "status": "admitted", "admittedTick": 0, … }
```

Pell gets `travel → mine ×4` at the scree slope; Jory gets
`rest` (his energy is 61 after the Crossing flavor event). You close the
browser. **The server's 1 Hz pump keeps the world moving; nothing notices
you left.**

**t+22 min.** Mara's `chop ×4` completes (61s → 58s at level 3… four times),
+48 wood carried, +136 xp → Woodcutting 4 (event `level.up` fires; the
chronicle pane will show it when you return). Her travel home completes at
**t+34 min**. Pell's mining finds the vein thinner than the survey
suggested: mine #3 fails soft — `ActionFailed{DEPLETED}` — and he stands
patient at the scree.

**t+41 min.** You come back on your phone. `/play` greets you with the
**"while you were away"** digest: 9 events, sorted, with links. You queue
Mara `build storehouse stage 2`, stage 30 wood at the beacon
(`stageShipment`), and — because the chronicle shows *"smoke past the ridge,
two nights out"* (the scripted raid's rumor at t+36h) — write the defense
plan (`writeDefensePlan`: Mara+Jory on the palisade, Pell fallback with
bandages).

**t+3h.** The ship arrives (`ShipmentArrival` heartbeat): 30 wood staged →
**+45 Favor**. The chronicle (public endpoint!) now reads
`Ashford shipped 30 timber; the Homeland breathes.` — this line is the
game's first show-off artifact.

**t+38h.** Raid tick. Resolution runs deterministically over (defense plan,
hold state, severity 2): gnarlings breach the east stack, steal 12 wood and
2 ore, damage the palisade 30%; **no one dies** (GP-D8); Jory takes a wound
debuff. Events stream out; the household gets a fogged rumor too.

**t+40h.** You dispatch the revenge expedition: `formParty` (all three,
after rest), `dispatchExpedition` to the barrow lair with the "hold and
flank" standing-order preset and crafted spears. It resolves over 40+
expedition beats (an hour of world time — you're asleep). Morning: victory,
loot (hide, iron shards — your first iron), Mara **dies holding the line**
(GP-D6's sting, arriving exactly on schedule in the slice's script).

**t+2 days.** You spend 60 Favor on a recruit; Brenna steps off the ship.
The roster is 3 again. **The loop is closed:** gather → ship → favor →
people → fight → loss → recover.

And then, in a terminal:

```bash
mvnd -q exec:java -pl apps/wilds-headless -- replay --season 0 --seed 1643… \
     --log db-export.jsonl --to 200000 --hash
# world hash = 7f3a9c…  — identical to the live server's hash at tick 200000.
```

**That last line is the slice's real finish line.**

### 4.1 Three sketches (the load-bearing shapes)

**The heap (M0):**

```java
public final class DueEventHeap {
    private record Entry(long dueMs, long seq, Continuation k) {}
    private final PriorityQueue<Entry> pq =
        new PriorityQueue<>(Comparator.comparingLong(Entry::dueMs)
                                      .thenComparingLong(Entry::seq));
    private long nextSeq;

    public long schedule(long dueMs, Continuation k) {
        pq.add(new Entry(dueMs, nextSeq, k));
        return nextSeq++;
    }

    /** Pop-and-apply in total order until dueMs > target; returns events emitted. */
    public void advanceTo(WorldState w, long targetMs, DomainEvent.Buffer out) {
        while (!pq.isEmpty() && pq.peek().dueMs <= targetMs) {
            var e = pq.poll();
            w.setNow(e.dueMs());
            Systems.apply(w, e.k(), this, out);   // may schedule more; may fail-soft
        }
        w.setNow(targetMs);
    }
}
```

**A rules row and the generic handler (M1):**

```java
public record ActionDef(String id, Kind kind, int baseTicks, int queueSlots,
                        Map<ItemId,Integer> inputs, Map<ItemId,Integer> outputs,
                        SkillId skill, int minXpLevel) {
    public enum Kind { GATHER, CRAFT, BUILD, TRAVEL, REST, STAGE, EXPEDITION }
}

// one handler interprets most of the catalog — new actions are usually just rows:
final class GatherHandler implements ActionHandler {
    public Started start(WorldState w, CharacterRow c, ActionDef a, ActionRequest r) {
        var site = w.sites().get(r.target());
        if (site == null || site.generation() != r.target().generation())
            return Started.fail("UNKNOWN_TARGET");
        if (site.stock() < a.outputs().values().iterator().next())
            return Started.fail("DEPLETED");           // fail-soft: event + queue advance
        return Started.ticks(DurationModel.ticks(a, c));
    }
}
```

## 8. Risks

| Risk | Mitigation |
|---|---|
| Determinism drift (the forever risk) | The M0 harness *is* the mitigation: goldens from day one, arch-test bans (Architecture §7), bless discipline |
| Float creep into state | Ban enforced by review + one reflection test (`WorldState` fields must be integral) |
| Slice scope creep (births! markets! maps!) | The §2 out-table is normative; every sweet idea goes to the post-slice list, not the milestone |
| Solo-Fridays cadence stalling mid-milestone | Milestones are S/M/L with story tests as the *only* definition of done — a stalled milestone is visible as a red test, not a feeling |
| Postgres ops on a hobby box | Single small instance; nightly dumps; the log is compressible; recovery story is the test suite (M3) |
| The web page rabbit hole | WI-D4: server-rendered + ~300 lines JS, hard budget; anything past 1k lines triggers the htmx conversation, not a rewrite |

## 9. Demo script (the 10-minute video this slice exists for)

1. `curl` a queue command; close the laptop. (P3/P8)
2. Open `/play` on a phone: "while you were away" digest, chronicle ticking. (P7)
3. Ship goods; show the *public* chronicle line about it. (first content artifact)
4. Write a defense plan live; let the raid resolve on stream. (GP-D8)
5. Dispatch the expedition; show the battle log beats. (GP-D6)
6. Mara dies. Talk about it for a second. Spend Favor on Brenna. (the sting + the loop)
7. Terminal: `wilds-headless replay …` → **same hash**. Land on determinism. (A1)

That video *is* the pitch for Ironwood Wilds — and it is fully constructible
from this slice and nothing more.
